\section{Design tensions and engineering justification}
\label{sec:tensions}

\begin{itemize}[leftmargin=*,itemsep=1pt,topsep=2pt]
  \item \textbf{Reliability vs latency.} \emph{Position:} TCP for all data, UDP only for discovery.
  \emph{Defence:} under 5\,\% loss every copy arrived complete, \textbf{2.1 times} slower; FTP slowed
  \textbf{2.3 times}, so it is TCP's price (Table~\ref{tab:experiments}). A corrupt file fails; a slow one does not.
  \item \textbf{Security vs performance.} \emph{Position:} HMAC authentication always, TLS~1.3
  optional. \emph{Defence:} TLS cost \textbf{nothing measurable}, as the Wi-Fi, not the CPU, is the bottleneck.
  FTP sent its password in \textbf{plain text} (frame 9); we send only nonces and MACs.
  \item \textbf{Compactness vs readability.} \emph{Position:} a 12-byte binary header, JSON for
  control messages. \emph{Defence:} the header is \textbf{0.016\,\%} of a 100\,MiB transfer
  (Section~\ref{sec:capture}). JSON costs more (over half of the 172\,KB sent after an edit), yet still beats a full
  copy \textbf{600 times} over and stays readable.
\end{itemize}
