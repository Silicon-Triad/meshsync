\section{AI-use declaration}
\label{app:ai-use}

We used one AI tool, Claude Code (Anthropic), with the Claude Opus~5.5 model and, for three
networking entries, Claude Sonnet~5.5; seven early entries do not record the model.
Table~\ref{tab:ai-use} summarises which parts of the work it was used for. The complete, dated
log, one entry per piece of work with what was kept or changed, is \code{docs/AI\_USE\_LOG.md}
in the repository (Appendix~\ref{app:code}). Under our rules (\code{AGENTS.md} §10), the AI must
post a plan for the member's approval before writing, must not invent protocol values or measured
numbers, and must never approve or merge; changes are merged only through a pull request with CI
and a review by another member.
